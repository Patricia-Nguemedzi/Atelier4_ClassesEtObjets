 Atelier 4 : Programmation Orientée Objet (POO) en Dart

Bienvenue dans le dépôt de l'Atelier 4 du cours de Développement d'applications (Techniques des Systèmes Informatiques - Collège Boréal).

Ce projet regroupe une série d'exercices pratiques visant à maîtriser les concepts fondamentaux de la programmation orientée objet avec le langage Dart.


# Notions couvertes

- Classes et Instances
- Constructeurs (classiques et simplifiés)
- Encapsulation (attributs privés et getters/setters)
- Propriétés et Méthodes statiques (static)
- Héritage(extends) et réutilisation du constructeur parent (super)
- Interfaces et Implémentation** (implements)
- Polymorphisme et redéfinition de méthodes (@override)


## Structure du Projet

| Fichier et Description 
| 
| exo1_Couleur.dart : Manipulation des couleurs et attributs
| exo2_CompteBancaire.dart : Gestion de solde, dépôts et retraits
| exo3_Media.dart : Introduction à l'héritage
| exo4_Formes.dart : Classes abstraites et polymorphisme
| exo5_ContratService.dart : Utilisation des interfaces (implements)
| exo6_Compteur.dart : Utilisation des variables statiques
| exo7_Compteur_Taches.dart : Compteur statique de tâches simples
| exo8_Livre.dart : Synthèse POO (Classes Livre et Roman, attributs privés, statiques et héritage) |


## Exécution des exercices

Pour exécuter l'un des fichiers Dart dans votre terminal :

dart run <nom_du_fichier>.dart

exemple : dart run exo8_Livre.dart
